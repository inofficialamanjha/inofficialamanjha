Project name: Page-RAG — Document-Grounded FAQ Assistant

Project URL: https://github.com/inofficialamanjha/Page-RAG

Built a Python-based product FAQ assistant that retrieves context from PDF documents and uses Azure OpenAI to generate document-grounded responses. 📄 Document ingestion — Implemented PDF parsing, page-aware content processing, chunking, and preprocessing to turn source documents into searchable representations. 🔎 Retrieval and generation — Connected query generation, vector search, page-level result deduplication, and response generation in a modular RAG pipeline. 💾 Persistent document recall — Used ChromaDB to retain indexed content across sessions, with command-line controls for adding files, saving the index, and resetting stored data. 🔌 Backend interfaces — Exposed document ingestion, search, and question-answering through Flask endpoints, including streamed responses, alongside an interactive command-line interface. Technologies: Python, Azure OpenAI, ChromaDB, Flask, and retrieval-augmented generation.
