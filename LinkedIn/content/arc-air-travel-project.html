Project name: ARC Air Travel Analytics & Trend Prediction

Project URL: Big Data Analysis and Trend Predictions — ARC Air Transaction Dataset

Built a notebook-based analytics and forecasting project using ARC air-transaction data to explore travel patterns and prototype booking-trend predictions for consumer and travel-industry use cases. 🧹 Data preparation — Used Python, pandas, and NumPy to standardize fields, inspect missing and invalid values, and enrich origin/destination airport codes with country information. ✈️ Journey reconstruction — Implemented segment-merging logic to derive trip origins and destinations from multi-leg transactions, supporting analysis of one-way, round-trip, and complex itineraries. 📈 Forecasting prototypes — Built Keras/TensorFlow LSTM experiments for booking-volume time series, using sequential train/test splits and visual comparisons of predictions with held-out observations. 📊 Analysis and communication — Used Matplotlib and Plotly to explore travel and booking patterns, and documented the workflow through notebooks, a project presentation, and a research report.

Skills to associate with this project

Python · Data Analysis · pandas · Time Series Forecasting · TensorFlow

Additional relevant technologies: NumPy, Keras, LSTM, Jupyter notebooks, Matplotlib, and Plotly.
